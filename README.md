# ZeitReihen
# @krampf_bot

# Telegram-бот для анализа и прогнозирования акций

> **Учебный проект** по анализу временных рядов (PJ).  
> Бот строит прогноз цены акций на **30 календарных дней**, формирует **BUY/SELL сигналы** по прогнозу и считает **условную прибыль**.  
> Дисклеймер: учебный проект, не финансовая рекомендация.

---

## Цель проекта

Сделать Telegram-бота, который по тикеру и сумме:

1. Загружает котировки за последние **2 года** (Yahoo Finance через `yfinance`);
2. Обучает и сравнивает **не менее 3 моделей разных классов** на тестовом отрезке;
3. Автоматически выбирает **лучшую модель по метрике** (RMSE/MAPE);
4. Строит прогноз на **30 календарных дней** и визуализирует его;
5. Анализирует прогнозный ряд и формирует рекомендации **BUY/SELL**;
6. Считает **условную прибыль** по стратегии и записывает всё в `logs.csv`.

---

## Основной функционал 

### 1) Ввод данных
Пользователь вводит:
- тикер (например: `AAPL`, `TSLA`, `MSFT`);
- сумму условной инвестиции (например: `1000`).

### 2) Прогноз и выбор модели
Бот обучает несколько моделей и оценивает их на **time-series holdout** (train → test):

- **Baseline (для контроля качества)**: `Naive` (последнее значение).  
     Baseline **не может быть выбран** как финальная модель — он используется только как точка отсчёта.
- **ML (классическая)**:
  - `LagRidge` (Ridge Regression с лаговыми признаками),
  - `Boosting` (HistGradientBoosting или XGBoost, если установлен `xgboost`).
- **Статистические**:
  - `ARIMA` (детерминированный прогноз),
  - `ETS` (Holt-Winters / ExponentialSmoothing).
- **Нейросеть (опционально)**:
  - `GRU` (используется, если установлен `torch`).

**Выбор победителя**: модель с минимальной ошибкой **среди non-baseline** моделей.

В сообщении пользователю показывается строка вида:
`Сравнение на тесте: Naive=..., LagRidge=..., ARIMA=..., ETS=..., GRU=...`

### 3) Визуализация
Бот отправляет 2 графика:

**График 1: История + прогноз на 30 дней**
- Линия прогноза (среднее значение).
- Полупрозрачная область — интервал неопределённости (если модель его поддерживает).
- Дополнительно текстом:
  - `Оптимистично: до ~X`
  - `Пессимистично: до ~Y`

**График 2: Сигналы и тренд**
- `EMA(5)` — краткосрочный импульс внутри прогноза.
- `EMA(20)` — общий тренд на горизонте месяца.
- EMA **не влияет на рекомендации**, используется только для визуализации.

### 4) Торговая стратегия
Бот анализирует прогноз и формирует сигналы:

**Основная стратегия (EXTREMA):**
- **BUY** — локальные минимумы на прогнозе;
- **SELL** — локальные максимумы на прогнозе.

**Fallback (BUY_HOLD):**
Если экстремумов нет или они недостаточно выражены:
- Купить **сегодня по текущей цене**;
- Продать в конце горизонта (30-й день прогноза).

Доход считается по введённой сумме (допускаются дробные акции).

### 5) Логирование
Каждый запрос автоматически записывается в `logs.csv` с полной информацией о прогнозе и стратегии.

Ошибки логируются в консоль с подробным traceback для отладки.

### 6) Демонстрационные материалы
Папка `reports/` содержит примеры работы бота:
- `logs.csv` — пример лог-файла с реальными запросами
- `scr_*.png` — скриншоты диалогов и графиков

Эти файлы используются для демонстрации функционала проекта.

---

## Лог-файл `logs.csv`

Файл создаётся автоматически в корне проекта.

**Колонки:**
- `timestamp` — время запроса
- `user_id` — id пользователя
- `ticker` — тикер
- `amount` — сумма инвестиции
- `metric_name` — RMSE или MAPE
- `model_scores` — сравнение всех моделей на тесте
- `chosen_model` — выбранная модель
- `metric_value` — метрика выбранной модели
- `baseline_metric` — метрика baseline (Naive)
- `improvement_ratio` — улучшение относительно baseline
- `current_price` — текущая цена акции
- `delta_abs`, `delta_pct` — прогнозируемое изменение цены
- `strategy_mode` — режим стратегии (`EXTREMA` или `BUY_HOLD`)
- `profit`, `cash_end` — результат симуляции торговли
- `trades_count` — количество сделок
- `optimistic_last`, `pessimistic_last` — границы интервала неопределённости
- `failed_models` — модели с ошибками обучения

## Установка и запуск

### Требования
- Python **3.10+** (рекомендуется 3.11)
- Интернет (для Yahoo Finance)
- Токен Telegram-бота от `@BotFather`

### 1) Клонирование
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd ts_bot_project
```

### 2) Виртуальное окружение
**Windows:**
```bat
py -m venv .venv
.venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3) Установка зависимостей (минимально)
```bash
pip install -r requirements.txt
```

### 4) Расширенные зависимости (опционально)
Чтобы включить GRU (torch) и XGBoost:
```bash
pip install -r requirements-ml.txt
```

### 5) Токен бота
Создай файл `.env` в корне проекта:
```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

⚠️ **ВАЖНО:** Файл `.env` содержит секретный токен и **не должен попадать в Git**! Проверьте наличие `.gitignore`.

### 6) Запуск
```bash
python app.py
```

Бот работает, пока запущен процесс. Логи выводятся в консоль.

## Обработка ошибок

Бот корректно обрабатывает различные ситуации:

| Проблема | Сообщение пользователю |
|----------|------------------------|
| Некорректный тикер | "Не удалось загрузить данные. Проверь тикер." |
| Недостаточно данных | "Недостаточно исторических данных. Попробуй другой тикер." |
| Ошибка обучения моделей | "Не удалось обучить модели. Попробуй позже." |
| Неожиданная ошибка | "Не смог обработать. Попробуй позже." |

Все ошибки **логируются с полным traceback** в консоль для отладки.
