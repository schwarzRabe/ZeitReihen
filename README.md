# ZeitReihen
# @krampf_bot

# Telegram-бот для анализа и прогнозирования акций

> **Учебный проект** по анализу временных рядов (PJ).  
> Бот строит прогноз цены акций на **30 календарных дней**, формирует **BUY/SELL сигналы** по прогнозу и считает **условную прибыль**.  
> Дисклеймер: учебный проект, не финансовая рекомендация.

---

## Цель проекта

Сделать Telegram-бота, который по тикеру и сумме:

1. Загружает котировки за последние **2 года** (Yahoo Finance через `yfinance`);
2. Обучает и сравнивает **не менее 3 моделей разных классов** на тестовом отрезке;
3. Автоматически выбирает **лучшую модель по метрике** (RMSE/MAPE);
4. Строит прогноз на **30 календарных дней** и визуализирует его;
5. Анализирует прогнозный ряд и формирует рекомендации **BUY/SELL**;
6. Считает **условную прибыль** по стратегии и записывает всё в `logs.csv`.

---

## Основной функционал 

### 1) Ввод данных
Пользователь вводит:
- тикер (например: `AAPL`, `TSLA`, `MSFT`);
- сумму условной инвестиции (например: `1000`).

### 2) Прогноз и выбор модели (по ТЗ)
Бот обучает несколько моделей и оценивает их на **time-series holdout** (train → test):

- **Baseline (для контроля качества)**: `Naive` (последнее значение).  
     Baseline **не может быть выбран** как финальная модель — он используется только как точка отсчёта.
- **ML (классическая)**:
  - `LagRidge` (Ridge Regression с лаговыми признаками),
  - `Boosting` (HistGradientBoosting или XGBoost, если установлен `xgboost`).
- **Статистические**:
  - `ARIMA` (детерминированный `forecast`, не `simulate`),
  - `ETS` (Holt-Winters / ExponentialSmoothing).
- **Нейросеть (опционально)**:
  - `GRU` (используется, если установлен `torch`).

**Выбор победителя**: модель с минимальной ошибкой **среди non-baseline** моделей.

В сообщении пользователю показывается строка вида:
`Сравнение на тесте (Naive — baseline): Naive=..., LagRidge=..., ARIMA=..., ETS=..., GRU=...`

### 3) Визуализация (Этап 3)
Бот отправляет 2 графика:

1) **История + прогноз на 30 дней**
- Оранжевая линия — прогноз (среднее).
- Полупрозрачная область — интервал неопределённости (если доступен).
- Дополнительно текстом:
  - `Оптимистично: до ~X`
  - `Пессимистично: до ~Y`

2) **Сигналы и тренд (визуально)**
- `EMA(5)` — краткосрочный импульс внутри прогноза.
- `EMA(20)` — общий тренд на горизонте месяца.
- EMA **не влияет на рекомендации**, используется только как визуализация.

### 4) Торговая стратегия (Этап 4 ТЗ)
Основная стратегия (по ТЗ):
- **BUY** — локальные минимумы на прогнозе `forecast(mean)`;
- **SELL** — локальные максимумы на прогнозе `forecast(mean)`.

Fallback (если экстремумов нет):
- **Buy&Hold**: купить **сегодня по текущей цене**, продать в конце горизонта (30-й день прогноза).

Доход считается по введённой сумме (допускаются дробные акции).

### 5) Логирование (Этап 5)
Каждый запрос пишется одной строкой в `logs.csv`.

---

## Лог-файл `logs.csv` (формат)

Файл создаётся автоматически в корне проекта (см. `config.py: log_path = Path("logs.csv")`).

- `timestamp` — время запроса
- `user_id` — id пользователя
- `ticker` — тикер
- `amount` — сумма
- `metric_name` — RMSE или MAPE
- `model_scores` — сравнение моделей на тесте
- `chosen_model` — выбранная модель
- `metric_value` — метрика выбранной модели
- `baseline_metric` — метрика baseline (Naive)
- `improvement_ratio` — улучшение относительно baseline
- `current_price` — текущая цена
- `delta_abs`, `delta_pct` — изменение к концу горизонта (по mean)
- `strategy_mode` — `EXTREMA` или `BUY_HOLD`
- `profit`, `cash_end` — итоговый результат стратегии
- `trades_count` — число сделок
- `optimistic_last`, `pessimistic_last` — границы интервала на последней точке (если доступны)
- `failed_models` — модели, которые не смогли посчитаться (если были)

## Установка и запуск

### Требования
- Python **3.10+** (рекомендуется 3.11)
- Интернет (для Yahoo Finance)
- Токен Telegram-бота от `@BotFather`

### 1) Клонирование
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd ts_bot_project
```

### 2) Виртуальное окружение
**Windows**
```bat
py -m venv .venv
.venv\Scripts\activate
```

**macOS/Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3) Установка зависимостей (минимально)
```bash
pip install -r requirements.txt
```

### 4) (Опционально) расширенные зависимости
Чтобы включить GRU (torch) и XGBoost:
```bash
pip install -r requirements-ml.txt
```

### 5) Токен
Создай `.env` рядом с `app.py`:
```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

### 6) Запуск
```bash
python app.py
```

Бот работает, пока запущен процесс (консоль/сервер).
